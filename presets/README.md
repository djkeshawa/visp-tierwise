# presets

Built-in presets (`tierwise:recommended`, `tierwise:minimal`,
`tierwise:entitlements`) are written in Phase 1 (work item 1.8). Their contents are
described in [requirements §5.1](../docs/requirements.md#51-tierwiseyaml); the
composition rules are in [ADR 0011](../docs/adr/0011-source-format-and-types.md).
