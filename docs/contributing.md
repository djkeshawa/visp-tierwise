# Contributing

The full guide is in the repository root's `CONTRIBUTING.md`. The short version:

- Find the current phase in the [roadmap](roadmap.md).
- Write the spec before the code, and tests alongside the code. Both languages read
  the shared conformance vectors directly.
- Every non-trivial decision needs an ADR. Every spec change needs an [RFC](rfc-template.md).
- Sign off every commit (DCO).
- Domain names belong in samples and fixtures only. Engine guarantees can never be
  disabled.
