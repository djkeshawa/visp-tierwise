# Specification

Phase 1 writes the language-neutral spec (`spec.md`), the error catalogue, JSON
Schemas, pinned data and the shared conformance vectors. The normative draft is
[requirements §4](../docs/requirements.md#4-semantics-normative-draft). The work
items are listed in [the implementation plan](../docs/implementation-plan.md#phase-1-spec-v01).
Once Phase 1 is accepted, this directory is authoritative for both implementations.
